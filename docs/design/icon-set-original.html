Semantic diff icons: an original set

Drawn for this, not taken from a library. Every icon is built from the same four pieces, so once you know them, each icon reads on its own. Colors are Pierre’s.

The four pieces

Solid block
code that is here
Dashed block
code that was here
Arrow
where it went, relative to a block
Dot
edited

The set

ChangeOld sideNew sideWhat it shows
Added
code that’s new here
A block with + (same idea as the squares GitHub uses)
Deleted
code that’s gone
A block with −
Edited
code changed in place
A block with a dot: kept, as you said
Moved
old: a dashed ghost of the block with an arrow leaving it. new: an arrow arriving at a solid block
Ghost = “was here”, solid = “is here now”. The two sides differ, so each says its own half of the story
Moved + edited
same as moved, but the arriving block carries the “edited” dot
Reuses the edited dot, so “moved + edited” reads as moved, then edited
Reordered
two blocks with up/down arrows
Order changed in place, not moved far. A different shape from Moved
Renamed
“ab” on a baseline
Your pick (whole-word), redrawn in the same stroke
Formatting only
a long line re-wrapped onto two
Says “same code, laid out differently”, which is what a reformat is. No eye (that means hidden)
Extracted
a function block with a dashed hole where some code was, and that piece now sitting outside it
“Take apart and move”: part of the block is now elsewhere
Inlined
the hole is filled, and the outside piece is just a dashed ghost
The exact reverse: the piece came back in, and its old home is gone
